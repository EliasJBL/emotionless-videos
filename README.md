# emotionless-videos

Production automatisée des vidéos TikTok / Instagram d'Emotionless : une chatte trader qui donne des conseils de discipline et de gestion du risque.

- `studio/` : moteur de montage (`engine.py`), poses du chat, polices.
- `specs/` : une spec JSON par vidéo.
- `tips/` : banque de conseils et liste des conseils déjà utilisés.
- `docs/videos/` : vidéos finales, servies par GitHub Pages pour Buffer.
- `PIPELINE.md` : mode d'emploi suivi par la tâche planifiée.
